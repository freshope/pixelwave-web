멀티도메인이므로 한 도메인씩 진행한다.

1. **invest-note** (`invest-note.pixelwave.app`) — 허브 도메인이 여기로 301 되므로 실트래픽 최우선.

## 기술 제약 (모든 프롬프트에 공통 적용)

AI 도구 산출물을 이식할 때 반드시 지킬 것:

- **스택**: Next.js 16 App Router + React 19 + Tailwind CSS **v4**.
  - v0 는 Tailwind v3 (`tailwind.config.js`) 기준 코드를 뱉는 경우가 많다. 이 레포는 v4 CSS-first(`@theme`) 라 **config 파일 없음** — 커스텀 토큰이 필요하면 `globals.css` 의 `@theme` 블록에 추가한다.
- **`globals.css` 의 베이스 엘리먼트 스타일(`h1`, `p`, `a`, `table` 등) 값 변경 금지** — `/privacy`, `/terms` 법무 페이지와 hub 가 공유한다. 랜딩 스타일은 페이지 내 Tailwind 유틸리티 클래스로만 작성한다. (`.hero`/`.features`/`.store-badges` 는 랜딩 전용이라 양쪽 랜딩 이식 완료 후 제거 가능.)
  - 베이스 엘리먼트 스타일은 `@layer base` 안에 있다([[D-21]]) — 유틸리티가 정상적으로 오버라이드하므로 랜딩에서 `text-5xl` 등 사용 가능. 신규 베이스 스타일도 반드시 `@layer base` 안에 작성.
- **서버 컴포넌트 유지**: `"use client"` 없이 동작해야 한다. 인터랙션(애니메이션 등)이 필요하면 CSS 로 해결.
- **기존 보존**: `export const metadata`, 스토어 URL 상수, `<Footer>` 컴포넌트(`@/components/Footer`), 루트 상대 링크(`/privacy`, `/terms` — 미들웨어 rewrite 로 도메인별 해석됨).
- shadcn/ui 컴포넌트를 쓰게 되면 직접 사용 금지 — `src/components/base/` 래퍼 경유 (AGENTS.md 규칙).
- 모든 노출 카피는 **한국어**. 폰트는 시스템 스택(Apple SD Gothic Neo / Pretendard) 유지.
- 모바일 퍼스트 반응형. 스토어 배지에 `aria-label` 유지.
- 이미지: 앱 스크린샷은 App Store 등록 스크린샷을 그대로 활용(폰 프레임 목업). 시안 단계에서는 플레이스홀더로 표시.

## 도메인 브리프 1 — 투자노트 (invest-note)

- **포지셔닝**: "흩어진 계좌, 한눈에 보는 포트폴리오" (App Store 부제와 통일)
- **무드**: 단정, 신뢰, 데이터 정밀. 금융 앱다운 차분한 네이비/블루 계열 + 손익 표현용 레드/그린 포인트. 과한 그라데이션·네온 금지.
- **타깃**: 여러 증권사 계좌를 쓰는 개인 투자자, 매매 복기를 하고 싶은 사람.

### 섹션 구성

1. **히어로**: 헤드라인 "흩어진 계좌, 한눈에 보는 포트폴리오" / 서브카피 "매매 이유와 감정까지 기록해 내 매매 패턴을 데이터로 객관화하는 매매일지 앱" / 스토어 배지 2개 / 앱 스크린샷(폰 목업)
2. **핵심 기능** (4~5 카드):
   - 3초 매매 입력 — 빠르게 기록하고 시장으로 복귀
   - 거래내역서 일괄 등록 — PDF/Excel 업로드로 자동 정리
   - 여러 증권사 계좌 통합 — 비중·평가손익·실현손익 한 화면
   - 승률·전략·감정 패턴 분석 — 어떤 판단이 수익을 냈는지 데이터로 확인
   - 자산 추이 차트 — 최대 2년 추이
3. **신뢰 섹션**: 데이터는 계정별 격리, HTTPS 암호화 (간결하게 1줄~배지 수준)
4. **마무리 CTA**: 스토어 배지 반복
5. **푸터**: 기존 `<Footer>` 그대로

## 도메인 브리프 2 — 오늘 하루 (today-alive)

- **포지셔닝**: **따뜻한 데일리 체크인** 중심. "오늘 하루 어땠나요?" — 하루 한 번 버튼으로 오늘을 기록하고, 쌓이는 날들이 소중한 사람에게 안부가 된다. 안부 알림(미확인 시 긴급연락처 자동 알림)은 **보조 안전장치**로 소개하고, '생존 신고/고립 방지' 프레이밍은 전면에 쓰지 않는다.
- **카피 금지어**: 감정 정리, 감정 기록, 다짐 — **앱에 해당 입력 기능이 없음** (2026-06-06 확인). App Store 설명에는 이 표현이 남아 있으나 랜딩에서 따라 쓰지 않는다.
- **무드**: 따뜻함, 잔잔함, 돌봄. 크림/피치/소프트 오렌지 등 저채도 따뜻한 팔레트. 부드러운 라운드, 넉넉한 여백.
- **타깃**: 하루 한 번 작은 리추얼을 원하는 사람, 혼자 지내는 가족이 걱정되는 사람.

   - 맞춤 알림 — 원하는 시간에 부드럽게(기본 오전 10시, 언제든 변경)
   - 나만의 테마 — 배경과 테마를 취향대로
3. **안전장치 섹션** (별도 섹션, 차분한 톤): "혹시를 위한 안부 알림" — 설정한 기간(1·3·5일) 동안 체크인이 없으면 미리 적어둔 메시지를 지정 연락처로 전합니다. 개인정보(이름·생년월일·연락처)는 알림에만 사용.
4. **마무리 CTA**: 스토어 배지 반복
5. **푸터**: 기존 `<Footer>` 그대로
